# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-18

### Added
- Multi-chain cryptocurrency wallet analysis (Ethereum, Bitcoin, Tron, Litecoin, Dogecoin, XRP, Cardano)
- FastAPI backend with REST API endpoints
- React + TypeScript frontend with Tailwind CSS
- OFAC sanctions registry integration
- Multi-factor risk scoring engine
- Case management system for investigations
- Court-ready PDF report generation
- Real-time blockchain data integration via Etherscan and TronGrid APIs
- Deployment configurations for Railway, Render, and Vercel
- Comprehensive API documentation
- CLI forensics engine with Rich terminal UI

### Changed
- Migrated from standalone CLI to full-stack web application
- Implemented API service layer with client-side fallback

### Security
- CORS configuration for API security
- Environment variable management for sensitive credentials
- Input validation for all API endpoints

## [0.1.0] - 2026-11-01

### Added
- Initial project structure
- Python forensic engine modules
- Basic wallet detection and balance checking
- SQLite database for case management
- Basic transaction intelligence
